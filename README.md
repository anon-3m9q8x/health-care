# NutriPath — アカウント同期対応版

メールアドレス・パスワードでのログインと、同一アカウントの端末間同期を追加しました。
**有効化にはSupabaseの設定が必要です。[アカウント設定手順](ACCOUNT_SETUP.md)を参照してください。**
未設定・未ログイン時は端末内保存です。ログイン中は食事・身体データをクラウドにも保存します。
以下は添付版の説明です。アカウント同期中の保存・通信・データ保護については上記の設定手順が最新です。

## 2026-11-07 コンビニ商品の統合・お茶の細分化

- セブン‐イレブン・ファミリーマート・ローソンで同じ内容の汎用商品（おにぎり 鮭 など）を1件に統合し、「◯◯で購入可」と取り扱い店舗を表示。各店独自の商品（ファミチキ、からあげクン、カフェ飲料など）は個別のまま。店舗を選ぶとその店で買える商品だけが表示され、おすすめもその店の組み合わせで計算します。
- お茶を商品名単位に細分化（綾鷹 ミネラル緑茶・濃いほうじ茶、伊右衛門 玄米茶・ジャスミン茶、生茶 熟成、お～いお茶 玄米茶・カフェインゼロ、十六茶ルイボスブレンド など）。お茶のブランド品は公式値で77品。スーパーの汎用「2L緑茶」なども2Lのブランド品に置き換え。

## 2026-11-07 飲料ラインナップ（メーカー・コンビニ公式値）

- サントリー・日本コカ・コーラ・キリン・アサヒ飲料・伊藤園の公式サイトに掲載された栄養成分で、主力飲料138品を「公式情報」として追加（容量分に換算）。購入場所（スーパー／コンビニ／自販機）を商品ごとに持ち、飲み物欄で絞り込めます。
- セブンカフェ・ファミマカフェは公式の栄養値と税込価格、ファミマのPB飲料は公式価格（栄養は想定）。ローソンの公式サイトは取得できなかったため、MACHI caféは想定値のまま。
- 価格：サントリー・伊藤園は希望小売価格（税別）×1.08、他メーカーは店頭価格の目安（「約」「想定」表示）。食物繊維はメーカー非掲載のため想定。
- 汎用の「緑茶 600ml」などの想定飲料は、ブランド品に置き換えて削除。

# NutriPath v2 — スマートフォン対応 食事・栄養・身体データ管理

2026-11-07版。NutriPath v1を拡張したブラウザアプリです。

## 重要：起動方法とスマホでの使い方

### パソコン
`NutriPath_v2_単体起動版.html` を開けば、食事管理・身体データの記録・食事提案をサーバー不要で利用できます。画像解析OCRだけは初回にインターネット接続が必要です。

### スマートフォン（推奨）
ZIPを解凍し、`index.html` を含むファイル群を **HTTPS の静的Webホスティング**（GitHub Pages / Cloudflare Pages / Netlifyなど）に配置してください。Safari/Chromeからアクセスし、ブラウザの「ホーム画面に追加」「アプリをインストール」で利用できます。PWA対応ファイル（manifest / service worker / icon）を同梱しています。

**iPhoneの「ファイル」アプリでHTMLを直接タップした場合、JavaScriptが動作しないプレビュー表示になることがあります。** その場合はHTTPS配信で利用してください。単体HTMLをブラウザで読み込める環境ならPWA配信なしでも主要機能が動作しますが、端末・ブラウザで制限があります。

※ 静的配信のアップロードは自身で行ってください。このアプリはサーバー、外部ログイン、クラウドDBを必要としません。

## 主な機能

- **モバイルUI**：画面下部の5タブ（今日 / おすすめ / メニュー / 分析 / からだ）、スマホ向けの1列レイアウト、大きめの操作領域、横スクロールできる店舗チップ、ダークモード。
- **身体プロフィール**：身長、体重、年齢/生年月日、基礎代謝推定計算用区分、活動量、減量・維持・増量目標、目標体重、腹囲、体脂肪率。
- **健診結果**：ALT/AST、中性脂肪、LDL/HDL、空腹時血糖、HbA1c、血圧（上/下）の任意登録。医療行為や診断はしません。
- **スクリーンショット取り込み**：スマホで撮影/選択した PNG/JPEG/WebP 等をプレビューし、初回オンラインで読み込む Tesseract.js によって日本語＋英語OCRを端末内で実行。認識候補をユーザーが修正し、**確認してから数値だけ保存**。
- **OCRの代替手段**：通信不可、認識精度不足、対応形式外の場合は、画像を見ながらレビュー欄に数値を直接入力。またはスマホの標準文字認識（画像内テキストをコピー）から貼り付けて候補抽出。
- **個別栄養目標**：成年の年齢・身長・体重・活動量から Mifflin–St Jeor の簡易式で基礎代謝/維持必要量を推定し、本人の目的別にエネルギー・PFC・食物繊維を設定。あくまで初期の概算。手動設定への切替も可能。食費目標は既存値を維持。
- **健康情報に応じた商品ランキング**：既存のおすすめアルゴリズムに、登録された血圧・中性脂肪などの記録を加味して塩分/食物繊維などの優先度を調整。特定疾患向けの安全な献立を保証するものではありません。
- **食事・購入管理**：朝・昼・夜・間食、摂取済み/予定、店舗絞り込み、商品ランキング、1日分自動献立、栄養・予算残額、週間分析。
- **商品データ**：v1の51件の初期メニューを引き継ぎ、7種の購入先に対応。追加登録・編集可。
- **体重の履歴**：測定日の記録と体重推移グラフ、履歴個別削除、身体データの一括削除。
- **データの取り扱い**：localStorageへ端末内保存。JSONバックアップ（v2形式）、CSVエクスポート、v1/v2のバックアップ復元に対応。

## スクリーンショットの登録手順

1. 画面下部「からだ」→「スクショを取り込む」を開きます。
2. 健康診断結果、体重計アプリ、体組成計アプリの画像を選択します。
3. 接続可能な場合にOCRが自動起動します。初回はWeb上からOCRのコードと日本語・英語モデルを取得します。画像そのものはアプリからアップロードしません。
4. 認識された候補と元画像を照らし合わせ、必要に応じて修正します（**誤認識に注意**）。
5. 「確認した数値を登録」を押すと、確認した項目をプロフィールに保存します。空欄の項目は既存値を変更しません。
6. 「プロフィールに合わせて目標を自動更新」がオン、かつ推定計算に必要な項目がそろっている場合は、栄養目標も再計算します。
7. 「今日」「おすすめ」に移動すると、新しい栄養目標と健診値を参照して献立が作られます。

**認識精度の制約：** 表の罫線・低解像度・傾き・複数列・日本語の文字間隔などにより誤読が起きます。誤って基準値を「実測値」と読む場合があります。OCR自動判定だけで保存しないでください。画像選択だけでは保存されません。

## 医療・栄養計算に関する注意

- 目標カロリーは推定式に過ぎません。妊娠中、授乳中、成長期（18歳未満）、疾病治療中、競技者、体重の大きな変化などは対象外です。
- 脂肪肝、肝機能異常、高血圧、脂質異常などについて、**アプリは診断・治療・服薬提案を行いません**。検査の異常は医師に相談してください。
- 商品のカロリー、価格、食塩相当量などは変更される場合があります。食品表示・公式情報を必ず確認してください。商品の一部の食物繊維は未確認であり「0」とは見なしません。
- 初期の商品情報は**2026-11-07時点**に作成したスナップショットです。外食チェーンの実売価格、在庫、アレルギー表示、栄養成分は自動更新されません。
- 推薦は商品の栄養・価格データに基づく **ルールベースのランキング**。医療的な食事制限やアレルギー安全性には対応していません。

## データ保護・復元

- OCRに選んだ画像はプレビューとOCR処理に使用するだけで、画像ファイル本体、OCR全文、氏名、住所は保存しません。保存するのは、確認した身体・健診の**数値、測定日と選択された計算条件**のみです。
- データは同じ端末・ブラウザ・Webサイトの保存領域内だけで管理されます。同期・暗号化・クラウドバックアップはありません。共有端末には保存しないでください。
- HTTPSで公開した静的サイトのURLを第三者に共有しても、通常はその第三者のブラウザにあなたの保存データがコピーされることはありません。ただしJSONバックアップを共有するとデータが含まれます。
- `設定・データ管理` → `JSONでバックアップ` から定期的に保存してください。新規ドメイン、ブラウザ変更、端末変更時の移行はバックアップの読み込みが必要です。
- **v1移行：** 同一オリジンでv1からv2へ切り替えた場合、旧 `nutripath.v1` の保存キーを引き継ぎます。異なるURL/端末の場合はv1でJSONバックアップを書き出し、v2で読み込んでください。

## OCRについての補足

- OCRエンジンの初回読み込みに `https://cdn.jsdelivr.net/npm/tesseract.js@6.0.1/dist/tesseract.min.js` を使用します。別途日本語・英語の文字認識モデルも取得するため、初回のみネット接続が必須です。オンライン環境でもネットワーク制限によりOCRが使用できない場合があります。
- メインアプリの食事管理・献立提案・プロフィール編集はオフライン利用可能。OCRのみ接続条件に依存します。
- OCRの読み取り処理が本番スマホで動くかどうかは端末・ブラウザ・接続条件に依存します。画像候補抽出のUI、レビュー、保存処理はデスクトップ／スマホ幅でテスト済みです。
